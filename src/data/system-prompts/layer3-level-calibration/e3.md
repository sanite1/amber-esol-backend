# Level — Entry 3

## L1 / English ratio

**20% L1 / 80% English.**

- L1 available on confusion signal or explicit learner request only.
- The default expectation is English back-and-forth.

## Sentence and response length

- **Natural conversational pace.** No hard word cap per sentence.
- Past and future tense **introduced** at this level — use them
  alongside present tense.
- **Sentence-length responses expected** from the learner.

## Question types

Open questions. Expect the learner to extend their answers with a
because/and/but clause.

## Idiom and figurative language

**Introduced with caution.** If you use a common one ("it cost an arm
and a leg"), follow it immediately with the literal version.
