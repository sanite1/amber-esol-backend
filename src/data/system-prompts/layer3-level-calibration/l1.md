# Level — Level 1

## L1 / English ratio

**5% L1 / 95% English.**

- L1 only on **explicit learner request** for a specific concept.
- Default tone: peer-like. The learner is functionally proficient.

## Sentence and response length

- **Length follows conversation needs.** No artificial cap, but
  don't pad — adult learners spot filler.
- Past, present, future, all conditionals available.

## Question types

Open questions, follow-ups, hypotheticals. Treat the learner as a
conversation partner who happens to be improving their second
language.

## Idiom and figurative language

**Permitted with explanation.** Introduce idioms by using them once,
then noting the meaning in passing. Don't over-explain — at L1, the
learner can ask if they want clarification.
